[One Word for the Boss](https://make.fun/c/u-swift-badger-44-one-word-for-the-boss-6b48c735)
competition on make.fun.

## The word

**Teflon.**

Nothing ever sticks to him — no blame, no consequence, no follow-up.
Every office has one: the boss who slides out of every mess spotless
while everyone else mops up.

## How it works

`main.py` writes exactly one word to `/output/entry.txt`:

```
Teflon
```

6 characters, no spaces, no caption, no explanation. The word stands alone.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
